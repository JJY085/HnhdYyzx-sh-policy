## 1. 项目目标

建设一个面向上海电力市场参与者的“政策学习地图”网站。

网站不是简单的政策文件仓库，而是将国家、华东区域、上海地方各层级电力市场规则按照“上位规则 → 区域规则 → 上海实施细则 → 专项政策”的关系组织起来。

用户应能通过卡片快速理解：

1. 这是什么政策；
2. 谁发布的；
3. 为什么出台；
4. 主要解决什么问题；
5. 主要规定了什么；
6. 它与其他政策是什么关系；
7. 官方原文在哪里。

除官方链接外，政策卡片及详情页均以文字字段为主。

```yaml

core_rules:

```

字段说明：

- `level`：国家 / 华东区域 / 长三角 / 上海
- `category`：现货 / 中长期 / 辅助服务 / 注册 / 信息披露 / 计量结算 / 新能源 / 绿电 / 跨省交易 / 市场监管 / 价格机制
- `status`：现行有效 / 历史版本 / 征求意见 / 待核验
- `official_url`：官方政策发布页
- `official_fulltext_url`：若存在官方 PDF/OFD/附件，填附件地址；没有则为 null
- `one_line_summary`：用于卡片
- `background`：解释为什么出台、此前有什么问题
- `significance`：制度定位和市场意义
- `main_content`：主要章节/制度内容
- `core_rules`：参与者最需要记住的规则
- `participant_relevance`：对发电、售电、用户、新能源、储能等主体的影响
- `notes`：版本说明、公开链接情况、需特别提醒的事项
- `last_verified`：政策信息最后核验日期

## POLICY-N001

### 《电力市场运行基本规则》

- id: `POLICY-N001`
- level: 国家
- category: 市场运行
- issuer: 国家发展和改革委员会
- document_no: 国家发展改革委令2024年第20号
- publish_date: 2024-05-14
- effective_date: 2024-07-01
- status: 现行有效
- official_url: https://www.ndrc.gov.cn/xxgk/zcfb/fzggwl/202405/t20240510_1377245.html
- one_line_summary: 全国各类电力市场共同遵循的顶层运行规则，是“1+6”规则体系中的“1”。
- keywords: 市场成员,经营主体,市场运营机构,市场交易,市场结算,风险防控,监管

**背景与意义**

随着全国统一电力市场建设推进，各地原有市场规则在主体定义、市场组织、交易机制和监管要求方面存在差异，需要一部适用于各类电力市场的统一上位规则。该规则明确电力市场基本制度、成员权责、交易组织、结算和风险管理，是全国电力市场规则体系的总纲。

**主要内容**

1. 明确电力市场适用范围和基本原则。
2. 定义经营主体、电力交易机构、电力调度机构、电网企业等市场成员。
3. 建立市场注册制度。
4. 明确电能量、辅助服务等市场交易基本框架。
5. 规定交易组织、合同执行、结算、信息披露和风险防控。
6. 对市场干预、争议处理和监督管理作出原则规定。

**核心规则**

- 各类经营主体参与电力市场前应完成市场注册。
- 市场运营机构包括交易机构和调度机构。
- 市场规则应保障统一、开放、竞争、有序。
- 中长期、现货、辅助服务等市场应协同衔接。

**对上海市场参与者的关系**

上海现货、中长期、辅助服务、注册、信息披露和计量结算细则均应与本规则保持一致。

## POLICY-N002

### 《电力中长期市场基本规则》

- id: `POLICY-N002`
- level: 国家
- category: 中长期市场
- issuer: 国家发展改革委、国家能源局
- document_no: 发改能源规〔2025〕1656号
- publish_date: 2025-12-26
- document_date: 2025-12-17
- status: 现行有效
- official_url: https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202512/t20251226_1402666.html
- one_line_summary: 统一全国数年、年度、月度和月内等中长期交易规则，并强化与现货市场衔接。
- keywords: 年度交易,月度交易,月内交易,跨省交易,合同曲线,现货衔接,绿电

**背景与意义**

2020版中长期交易规则形成后，新能源全面入市、现货市场扩大、绿电交易、新型储能和虚拟电厂等快速发展。2025版规则对原规则进行系统修订，并将绿电交易相关内容纳入统一中长期规则体系。

**主要内容**

1. 规定数年、年度、月度、月内等不同周期交易。
2. 统一经营主体、交易组织、出清和合同执行原则。
3. 强化跨省跨区与省内市场衔接。
4. 强化中长期与现货市场在交易时序、出清和结算上的衔接。
5. 将绿色电力交易相关制度融入统一规则体系。
6. 对新型经营主体参与中长期市场作出制度安排。

**核心规则**

- 中长期交易用于锁定未来电量和价格、管理市场风险。
- 市场周期包括数年、年、月、月内等。
- 中长期合同必须与现货市场结算机制协调。
- 各省和区域应根据国家规则制定实施细则。

## POLICY-N003

### 《电力现货市场基本规则（试行）》

- id: `POLICY-N003`
- level: 国家
- category: 现货市场
- issuer: 国家发展改革委、国家能源局
- document_no: 发改能源规〔2023〕1217号
- publish_date: 2023-09-07
- status: 现行有效
- official_url: https://zfxxgk.nea.gov.cn/2023-09/07/c_1310741791.htm
- one_line_summary: 规定日前、日内和实时电力现货市场建设、运行、出清、价格和结算的全国基础规则。
- keywords: 日前,实时,安全约束,节点电价,统一结算,市场限价,市场干预

**背景与意义**

各试点地区现货市场建设进度和规则差异较大，需要建立全国统一的现货市场基本制度。该规则为各省现货实施细则提供上位依据。

**主要内容**

1. 明确现货市场基本模式和市场成员。
2. 明确日前、日内、实时市场组织。
3. 明确安全约束机组组合和经济调度的基本原则。
4. 规定价格形成、市场限价和异常价格处置。
5. 明确中长期与现货衔接。
6. 规定现货市场结算、信息披露和风险防控。

**核心规则**

- 现货市场通过竞争形成体现电力时间和空间价值的价格。
- 市场出清必须满足电力平衡、机组运行和电网安全约束。
- 现货市场应与中长期交易协同。
- 市场限价和市场干预必须由规则明确。

## POLICY-N004

### 《电力辅助服务市场基本规则》

- id: `POLICY-N004`
- level: 国家
- category: 辅助服务
- issuer: 国家发展改革委、国家能源局
- document_no: 发改能源规〔2025〕411号
- publish_date: 2025-04-29
- document_date: 2025-04-03
- status: 现行有效
- official_url: https://www.nea.gov.cn/20250429/df8e465e859245039b24fbbe21f04c5f/c.html
- one_line_summary: 统一调频、备用、爬坡等辅助服务市场基本制度，强化与现货电能量市场衔接。
- keywords: 调频,备用,爬坡,辅助服务,费用分摊,联合出清

**背景与意义**

新能源占比提升后，系统灵活性和调节能力需求快速增加。原有主要依靠行政补偿的辅助服务机制需要进一步市场化。

**主要内容**

1. 建立统一规范的辅助服务市场体系。
2. 明确辅助服务需求、品种和提供主体。
3. 规定市场申报、出清、价格和结算机制。
4. 建立“谁提供、谁获利，谁受益、谁承担”的费用机制。
5. 强化辅助服务与现货电能量市场联合优化。
6. 明确现货连续运行地区调峰功能逐步由现货价格机制承担。

**核心规则**

- 调频、备用、爬坡是重点市场化辅助服务品种。
- 新型储能、可调节负荷等可按规则参与。
- 现货连续运行地区原则上不再单独运行功能重复的调峰市场。

## POLICY-N006

### 《电力市场信息披露基本规则》

- id: `POLICY-N006`
- level: 国家
- category: 信息披露
- issuer: 国家能源局
- document_no: 国能发监管〔2024〕9号
- publish_date: 2024-01-31
- status: 现行有效
- official_url: https://zfxxgk.nea.gov.cn/2024-01/31/c_1310763726.htm
- one_line_summary: 统一电力市场信息披露分类、主体、内容、时间和责任要求。
- keywords: 信息披露,公开信息,特定信息,私有信息,交易数据,市场透明度

**背景与意义**

市场化交易需要充分、及时、对称的信息。各地披露内容和时效差异会影响公平交易，因此需要统一基本标准。

**主要内容**

1. 明确信息披露主体。
2. 对公开信息、特定信息等进行分类。
3. 规定市场运营、供需、价格、交易结果等披露要求。
4. 明确披露时效、准确性和责任。
5. 建立信息披露监督机制。

**对网站的重要性**

该政策决定上海市场参与者在每个时间点理论上能够获得哪些信息，也是构建预测模型、防止未来信息泄漏的重要规则依据。

**背景与意义**

2. 区分“形成结算依据”和“电费结算”。
3. 规范结算数据、结算周期和账单。
4. 对清算、追退补和异常数据处理作出规定。
5. 推进现货连续运行地区规范化结算。

## POLICY-N008

### 《关于深化新能源上网电价市场化改革 促进新能源高质量发展的通知》

- id: `POLICY-N008`
- level: 国家
- category: 新能源
- issuer: 国家发展改革委、国家能源局
- document_no: 发改价格〔2025〕136号
- status: 现行有效
- one_line_summary: 推动新能源上网电量原则上全面进入市场，并建立新能源可持续发展价格结算机制。
- keywords: 136号文,新能源入市,机制电价,差价结算,市场化电价

**背景与意义**

新能源规模快速扩大后，固定或保障性上网电价难以充分反映市场供需和系统价值，因此推动新能源全面进入市场，并通过市场外差价机制平滑收入风险。

- 二级限价会改变极端价格日的实际结算结果。

```text
Codex 开发
    ↓
GitHub Repository
    ↓
Vercel
    ↓
公网访问
```

- 后续可绑定独立域名；
- 后续可扩展 API、数据库和用户系统。

## 24.2 第一版技术原则

```text
src/data/policies.json
src/data/policy-relations.json
src/data/tags.json
```

或等价的 TypeScript 数据文件中。

页面运行时应从本地结构化数据读取政策卡片，不依赖远程数据库。

第一版应支持：

- 响应式布局
- 公网部署

## 24.3 部署平台要求

Codex 应优先保证项目可直接部署到 Vercel。

- 不依赖本地绝对路径；
- 不依赖仅本机可用的环境；
